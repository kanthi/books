Linux Engineering & Administration

Reference platform: Ubuntu 26.04 LTS (“Resolute Raccoon”). This book covers general Linux engineering plus modern Ubuntu-specific administration. Newer releases and non-Ubuntu distributions are compatibility targets.

Version policy: Ubuntu 26.04 introduced Linux 7.0 on its generic kernel track, made sudo-rs the default sudo provider, and uses rust-coreutils as the default core-utilities provider. OpenSSH 10.2 includes hybrid post-quantum key-exchange support (mlkem768x25519-sha256). Pure cgroup v2, APT 3.1, Chrony NTS, AppArmor 4.x, and TPM2 hardware-backed FDE define the modern host baseline.

How to Use This Book

  • Build knowledge in order: foundations (01–04), core host administration (05–08), virtualization and containers (09–10), then automation and platform operations (11–12). Use appendices (13) as reference material.
  • For every chapter, topics include: purpose and mental model, prerequisites, safe inspection commands, a minimal working example, failure modes, recovery steps, security considerations, and primary documentation links.
  • Portable Linux behavior is kept separate from Ubuntu 26.04-specific behavior. Distro-specific, desktop-only, cloud-provider-specific, optional, and experimental features are explicitly labeled.
  • Safety: Run destructive exercises only in disposable VMs or lab hardware with snapshots/backups. Never test disk, boot, firewall, identity, encryption, or cluster recovery procedures on production systems.

Master Roadmap Overview (Parts 05–13)

Part 05: Systems Administration (Ubuntu 26.04 LTS Reference)

  • 5.1 Boot Architecture, UEFI & Firmware: BootROM, ESP (/boot/efi), MOK (mokutil, sbctl), TPM 2.0 PCRs, GRUB 2, systemd-boot, Dracut/initramfs-tools, split linux-firmware, fwupd.
  • 5.2 Automated Provisioning & Installation: Subiquity autoinstall schema, Cloud-Init stages & modules, UEFI HTTP Boot vs TFTP/iPXE netboot.
  • 5.3 Identity, Privilege & Authentication: /etc/shadow (yescrypt), sudo-rs architecture & policy migration, PAM modules (pam_faillock), Canonical authd OIDC broker, SSSD Active Directory / FreeIPA.
  • 5.4 Package Management (APT, DEB & Snap): APT dependency solver diagnostics, DEB822 (ubuntu.sources), dpkg packaging, Unattended Upgrades, Ubuntu Pro (ESM, USG, Livepatch), Snapd strict confinement.
  • 5.5 systemd & Unified cgroup v2 Resource Control: Unit lifecycle and types, hardened services (DynamicUser, ProtectSystem), timers & socket activation, pure cgroup v2 controllers and slice hierarchies.
  • 5.6 Time, Logging & Kernel Diagnostics: Chrony 4.8 NTS default, systemd journal structured queries & verify, runtime sysctl, GPU/AI compute stacks (CUDA, ROCm, NPU /dev/accel/*), kdump & Sysprof.
  • 5.7 Systems Administration Workbook: Rescue labs, authd + sudo-rs setup, hardened systemd service engineering.

Part 06: Storage, Filesystems & Encryption

  • 6.1 Block Layer, NVMe & Partitioning: I/O schedulers, GPT partitioning (parted, sgdisk), nvme-cli, DM-Multipath.
  • 6.2 Hardware-Backed Disk Encryption: TPM2 + FDE sealing, LUKS2 JSON metadata & Argon2id PBKDF, systemd-cryptenroll (TPM2/FIDO2/PKCS#11), Tang/Clevis NBDE.
  • 6.3 Filesystems Deep Dive: Ext4 internals & tuning, XFS high-performance allocations, Btrfs subvolumes & snapshots, OpenZFS VDEVs, pools, datasets, and native encryption.
  • 6.4 LVM2 & Software RAID: Volume groups, thin pools, NVMe writecache, pvmove online migrations, mdadm RAID arrays.
  • 6.5 Mounting, Automount & Swap: VFS mount options, systemd .mount/.automount, modern swapfiles, zram-config, systemd-oomd.
  • 6.6 Networked & Object Storage: NFSv4.2 with Kerberos (krb5p), Samba SMB3, iSCSI initiator/targets, Canonical MicroCeph (RBD, CephFS, RGW).
  • 6.7 Performance, Health & Backups: smartctl, fio benchmarking, database storage tuning (PostgreSQL/Valkey), 3-2-1 backup engineering (restic, borg).
  • 6.8 Storage Workbook: ZFS RAIDZ2 + LUKS2 lab, zero-downtime LVM migration, 3-node MicroCeph deployment.

Part 07: Network Administration

  • 7.1 Network Stack & TCP/IP Internals: Ring buffers, NAPI, sk_buff, Netfilter hooks, XDP, IPv4/IPv6 CIDR, policy routing (ip rule, multiple tables).
  • 7.2 Netplan & Network Managers: Netplan YAML hierarchies, VLANs, LACP bonding (802.3ad), bridge & VRF topologies, systemd-networkd.
  • 7.3 DNS & Name Resolution: systemd-resolved stub, DoT, DNSSEC, authoritative BIND9, recursive Unbound / CoreDNS.
  • 7.4 Core Edge Services: Modern ISC Kea DHCP, Nginx HTTP/3 QUIC reverse proxy, HAProxy + Keepalived VRRP active/passive pairs.
  • 7.5 Virtual Networking & SDN: Network namespaces (netns), veth, VXLAN overlays, Open vSwitch & MicroOVN, FRRouting dynamic BGP/OSPF.
  • 7.6 VPNs & Zero-Trust Mesh: WireGuard cryptographic tunnels, Tailscale / self-hosted Headscale mesh, strongSwan IKEv2 IPSec.
  • 7.7 Capture & Diagnostics: ss, conntrack-tools, tcpdump BPF filtering, tshark, dropwatch.
  • 7.8 Network Workbook: Bonded LACP trunk with VLANs, HA edge load balancer, WireGuard + BGP mesh.

Part 08: Security, Cryptography & Hardening

  • 8.1 Discretionary Access & Capabilities: Permissions, POSIX ACLs, file attributes (chattr +i), Linux capabilities (capsh, ambient sets).
  • 8.2 Mandatory Access Control (AppArmor): AppArmor LSM architecture, profile engineering (aa-genprof, aa-logprof), desktop/snap prompt mediation.
  • 8.3 Post-Quantum OpenSSH 10.2: PQ-KEX (mlkem768x25519-sha256), FIDO2 hardware keys, PerSourcePenalties, zero-trust SSH Certificate Authority (CA).
  • 8.4 Host Firewalls & Active Defense: Native nftables tables/chains/sets, UFW application profiles, CrowdSec intrusion detection & nftables bouncers.
  • 8.5 Cryptography & PKI: OpenSSL 3.x, memory-safe Rustls, private step-ca ACME server with mTLS, Let’s Encrypt Certbot, modern age encryption.
  • 8.6 Kernel Hardening & Auditing: Kernel lockdown mode, security sysctl, auditd syscall auditing, AIDE file integrity, CIS benchmarks via Ubuntu Security Guide (USG).
  • 8.7 Security Workbook: Zero-trust SSH CA, custom AppArmor profile + stateful nftables, CIS Level 2 server audit.

  • 9.3 PCIe & GPU Passthrough: IOMMU groups, vfio-pci isolation, passing NVIDIA/AMD GPUs & NPUs to guests, SR-IOV virtual functions.
  • 9.4 LXD & Incus: System containers vs --vm guests, ZFS/Ceph storage pools, clustering, live migration, MicroOVN virtual networks.
