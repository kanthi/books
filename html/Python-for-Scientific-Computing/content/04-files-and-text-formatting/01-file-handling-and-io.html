Chapter 10: File Handling and I/O

Laboratory sensors, data loggers, and simulation engines store their results in files (such as .csv, .txt, or .dat). To analyze this data, you must be able to open files, read their contents, process numerical tables, and write processed summaries back to disk.

+-------------------------------------------------------------------------+
|                          FILE INPUT / OUTPUT                            |
|                                                                         |
|  [ Data File on Disk ]  ──►  open("data.txt", "r")  ──►  Python Program |
|       (Permanent)                                            (RAM)      |
|                                                                         |
|  [ Summary Report ]    ◄──  open("out.txt", "w")   ◄──  Python Program |
+-------------------------------------------------------------------------+

10.1 File Objects and open()

The built-in function open(filename, mode) connects your Python program to an operating system file and returns a file object:

file_obj = open("experiment.txt", "w")

10.2 File Object Attributes

File objects provide attributes to check their state:

Attribute Description Example
f.name Name or path of the file 'experiment.txt'
f.mode Access mode used 'w'
f.closed True if the file has been closed False

10.3 File Access Modes

The mode string tells Python what operations are permitted:

+-------+-----------------------------------------------------------------+
| Mode  | Behavior                                                        |
+-------+-----------------------------------------------------------------+
|  'r'  | Read-only (default). File must exist, or FileNotFoundError.     |
+-------+-----------------------------------------------------------------+
|  'w'  | Write-only. Overwrites existing file or creates a new one!      |
+-------+-----------------------------------------------------------------+
|  'a'  | Append-only. Adds new data to the end without deleting past.    |
+-------+-----------------------------------------------------------------+
|  'r+' | Read and write simultaneously.                                  |
+-------+-----------------------------------------------------------------+

10.4 Reading Data: read(), readline(), and readlines()

Python offers three ways to extract text from a file:

1. f.read()        ──► Reads the ENTIRE file into a single giant string.
2. f.readline()    ──► Reads one single line (up to next \n).
3. f.readlines()   ──► Reads all lines into a LIST of strings: ['line1\n', 'line2\n']

Runnable Example

# First, let us create a sample data file
with open("sensor_log.txt", "w") as f:
    f.write("Time(s),Voltage(V)\n")
    f.write("0.0,0.02\n")
    f.write("0.5,1.25\n")
    f.write("1.0,2.48\n")

# Method A: Iterating directly over the file line-by-line (Most memory efficient!)
print("--- Iterating line-by-line ---")
with open("sensor_log.txt", "r") as f:
    for line in f:
        # strip() removes trailing newline \n
        print("Line:", line.strip())

# Method B: readlines() to get a list
with open("sensor_log.txt", "r") as f:
    all_lines = f.readlines()
    print("\nReadlines list:", all_lines)

10.5 Writing Data: write() and writelines()

  • f.write(string): Writes a string. Unlike print(), it does not automatically add a newline \n. You must add \n explicitly!
  • f.writelines(list_of_strings): Writes a list of strings to the file.

Runnable Example

measurements = [23.1, 24.5, 23.8, 25.2]

with open("output_data.txt", "w") as f:
    f.write("# Temperature Log\n")
    for idx, val in enumerate(measurements, start=1):
        f.write(f"Sample {idx}: {val:.2f} C\n")

print("File written successfully!")

10.6 The with Statement (Context Manager)

In older Python code, you had to remember to call f.close() manually:

# Old, risky way (if an error occurs between open and close, file stays locked!)
f = open("data.txt", "r")
data = f.read()
f.close()

Always use the with statement instead:

with open("data.txt", "r") as f:
    data = f.read()
# The file is GUARANTEED to close automatically here, even if errors occur!

10.7 Reading and Writing Numerical Data with NumPy

While Python’s built-in file methods work for text, NumPy provides specialized functions for reading and saving tabular numerical arrays:

  • np.savetxt(filename, array, delimiter=","): Writes an array to CSV/text.
  • np.loadtxt(filename, delimiter=",", skiprows=1): Loads text into an ndarray.

Runnable Example

import numpy as np

# 1. Generate numerical experiment data
time = np.linspace(0, 2, 5)
signal = np.sin(2 * np.pi * time)

# Combine into two columns: shape (5, 2)
dataset = np.column_stack((time, signal))

# 2. Save directly to CSV with a header
np.savetxt("signal_data.csv", dataset, delimiter=",", 
           header="Time(s),Signal(V)", comments="", fmt="%.4f")
print("Saved array to 'signal_data.csv'")

# 3. Read it back in one line!
loaded_data = np.loadtxt("signal_data.csv", delimiter=",", skiprows=1)
print("\nLoaded data array back from disk:")
print(loaded_data)
print("Shape:", loaded_data.shape)
