0.1 Downloading and Installing Anaconda

What is Anaconda?

Python by itself is just an execution engine. In scientific computing, you also need hundreds of specialized packages for matrix mathematics, statistics, graph plotting, and numerical simulation.

Installing them individually can lead to complex dependency conflicts. Anaconda Distribution solves this: it is a free, all-in-one package manager and software bundle containing Python, all major scientific libraries (NumPy, SciPy, Matplotlib, pandas), and IDEs like Spyder.

Platform Instructions

Windows

  1. Visit https://www.anaconda.com/download and download the Windows 64-Bit Graphical Installer.
  2. Run the downloaded .exe installer.
  3. Click Next -> I Agree.
  4. Choose Just Me (recommended).
  5. Choose the default destination folder (e.g., C:\Users\<YourUsername>\anaconda3).
  6. In the Advanced Options screen:
    • Check “Register Anaconda3 as my default Python”.
    • You can leave “Add Anaconda3 to my PATH environment variable” unchecked (Anaconda provides its own dedicated command prompt).
  7. Click Install. Once finished, click Finish.

macOS

  1. Download the macOS Graphical Installer (choose Apple Silicon or Intel, matching your Mac).
  2. Double-click the .pkg file and follow the on-screen prompts.
  3. Accept the default location in your home directory.
  4. Complete the installation.

Linux

  1. Download the installer script (Anaconda3-xxxx.xx-Linux-x86_64.sh).

  2. Open your terminal, navigate to your downloads directory, and run:

    bash Anaconda3-2026.xx-Linux-x86_64.sh

  3. Press Enter to scroll through the license terms, type yes to accept, and press Enter to accept the default installation directory.

  4. When prompted: Do you wish to initialize Anaconda3 by running conda init?, type yes.

0.2 Anaconda Navigator vs Anaconda Prompt, and Launching Spyder

Anaconda provides two ways to launch tools and manage packages:

                  +------------------------------+
                  |     Ways to Access Tools     |
                  +--------------+---------------+
                                 |
         +-----------------------+-----------------------+
         v                                               v
+------------------------------+               +-------------------+
|     Anaconda Navigator       |               |  Anaconda Prompt  |
|  (Point-and-click graphical  |               |   (Command-line   |
|          dashboard)          |               |     terminal)     |
+------------------------------+               +-------------------+
  1. Anaconda Navigator (GUI): A visual desktop program.
    • Open your Start Menu (Windows), Applications folder (macOS), or run anaconda-navigator in Linux.
    • You will see cards for Jupyter Notebook, Spyder, and other tools.
    • Click the Launch button under the Spyder tile.
  2. Anaconda Prompt / Terminal (CLI):

    • On Windows, search for Anaconda Prompt in the Start Menu.

    • On macOS/Linux, open your standard Terminal.

    • Simply type spyder and press Enter:

      spyder

0.3 Creating and Activating a Conda Environment

An environment is an isolated sandbox. Imagine having one project that requires a specific version of a library and another project that needs a newer version. Environments prevent projects from interfering with one another.

+-----------------------------------+-----------------------------------+
|      Environment: base            |      Environment: sci-college     |
|   - Python 3.12                   |   - Python 3.12                   |
|   - NumPy 2.x                     |   - NumPy 2.x                     |
|   - Matplotlib 3.x                |   - Matplotlib 3.x                |
|   - System defaults               |   - Your custom project packages  |
+-----------------------------------+-----------------------------------+

Essential Conda Commands

Let us create an environment named college_env for this book:

# 1. Create a new environment with Python and scientific packages
conda create -n college_env -c conda-forge \
    python=3.12 numpy matplotlib spyder -y

# 2. Activate the environment
conda activate college_env

# 3. Verify which environment is active (indicated by an asterisk *)
conda env list

# 4. To deactivate when you are done for the day:
conda deactivate

Once activated, your terminal prompt changes from (base) to (college_env). You can now type spyder to launch Spyder configured with this environment.

0.4 Checking Installed Versions

Let us verify that Python, NumPy, and Matplotlib are properly installed. Open Spyder, look at the IPython Console in the bottom-right panel, type each of the following lines, and press Enter:

import sys
import numpy as np
import matplotlib

print("Python version:    ", sys.version.split()[0])
print("NumPy version:     ", np.__version__)
print("Matplotlib version:", matplotlib.__version__)

Expected output:

Python version:     3.12.x
NumPy version:      2.x.x
Matplotlib version: 3.x.x

If these three lines execute without error and display your version numbers, your scientific computing installation is complete and ready.

0.5 Tour of the Spyder 6 IDE

Spyder (Scientific Python Development Environment) is tailored specifically for scientists and engineers. Unlike generic text editors, Spyder includes built-in tools for visualizing data structures and plots.

+------------------------------------+------------------------------------+
|  [1] EDITOR (Left Panel)           |  [3] VARIABLE EXPLORER / PLOTS /   |
|                                    |      FILES / HELP (Top-Right)      |
|  1  import numpy as np             |                                    |
|  2  x = np.linspace(0, 10, 50)     |  Name   Type      Size   Value     |
|  3  y = np.sin(x)                  |  x      ndarray   (50,)  [0. ... ] |
|  4                                 |  y      ndarray   (50,)  [0. ... ] |
|                                    +------------------------------------+
|                                    |  [2] IPYTHON CONSOLE (Bottom-Right)|
|                                    |                                    |
|                                    |  In [1]: runfile('script.py')      |
|                                    |  In [2]: x.mean()                  |
|                                    |  Out[2]: 5.0                       |
+------------------------------------+------------------------------------+

Key Panes:

  1. Editor (Left): Where you write, save, and edit Python files (.py). Features line numbers, syntax highlighting, and auto-indentation.
  2. IPython Console (Bottom-Right): An interactive prompt where you can execute code immediately line-by-line, test ideas, and see immediate outputs.
  3. Variable Explorer (Top-Right): One of Spyder’s greatest superpowers! Every variable created in your code appears in a table showing its name, data type, size, and value. Double-clicking any list or array opens a graphical viewer.
  4. Plots Pane (Top-Right): Whenever you generate a graph with Matplotlib, the image is captured here as a thumbnail gallery so you never lose previous figures.
  5. Files Pane (Top-Right): A built-in file explorer to browse, open, and organize files in your current working folder.
  6. Help Pane (Top-Right): Type any function name or press Ctrl + I (Cmd + I on Mac) while your cursor is on a function in the Editor to view its official documentation.
  7. Debugger Pane: Allows stepping through code line-by-line during troubleshooting.

0.6 Running Code in Spyder: Three Ways

Spyder gives you three distinct ways to execute code, each suited for different tasks:

+----------------+---------------------+-----------------------------------+
| Method         | Shortcut            | Best Used For                     |
+----------------+---------------------+-----------------------------------+
| 1. Run File    | F5                  | Running the complete script from  |
|                |                     | start to finish.                  |
+----------------+---------------------+-----------------------------------+
| 2. Run Cell    | Ctrl+Enter (Win/Lin)| Running a dedicated block marked  |
|                | Cmd+Enter (Mac)     | with #%% without rerunning all.   |
+----------------+---------------------+-----------------------------------+
| 3. Run Selected| F9                  | Running only the highlighted      |
|    Code        |                     | lines of code.                    |
+----------------+---------------------+-----------------------------------+

Try it Yourself: Code Cells (#%%)

In Spyder, typing #%% at the beginning of a line splits your script into a separate, runnable cell. Copy this code into the Spyder Editor:

#%% Cell 1: Define parameters
initial_velocity = 25.0   # meters per second
gravity = 9.81            # m/s^2
time = 2.0                # seconds

#%% Cell 2: Calculate height of a projectile
# Formula: h = v0*t - 0.5*g*t^2
height = initial_velocity * time - 0.5 * gravity * (time ** 2)
print("Projectile height at t =", time, "seconds is", height, "meters")

  1. Click anywhere inside Cell 1 and press Shift + Enter (runs the cell and moves to the next).

  2. Look at the Variable Explorer—you will see initial_velocity, gravity, and time appear instantly!

  3. Press Ctrl + Enter inside Cell 2. The console prints:

    Projectile height at t = 2.0 seconds is 30.38 meters

  4. Now height also appears in the Variable Explorer.

0.7 Setting the Working Directory and Project Folders

When Python reads or writes a file (such as saving a graph or loading a lab dataset), it looks in its Current Working Directory (CWD).

In Spyder, look at the top-right toolbar. You will see a folder path with an open folder icon next to it:

[ Directory Path: /home/user/College_Python/Lab1 ]  [📁 Browse]

Best Practice for College Labs:

  1. Create a dedicated folder on your computer for your course, e.g., Documents/Python_Labs/.

  2. For every assignment or chapter, create a subfolder: Chapter00/, Chapter01/, etc.

  3. In Spyder, click the Browse folder icon (📁) and select that folder.

  4. Alternatively, execute this in the IPython console:

    import os
os.chdir("/path/to/your/folder")  # Sets the current directory
print("Current working folder:", os.getcwd())
