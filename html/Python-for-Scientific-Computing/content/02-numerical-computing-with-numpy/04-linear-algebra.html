Chapter 7: Linear Algebra with numpy.linalg

Linear algebra is the backbone of engineering analysis, quantum mechanics, computer vision, and machine learning. NumPy’s numpy.linalg submodule bundles high-performance linear algebra routines wrapping industry-standard LAPACK and BLAS libraries.

       Matrix Equation:   A · x = b
       
       +---------+   +---+   +----+
       | 3    1  |   | x |   |  9 |
       | 1    2  | · | y | = |  8 |
       +---------+   +---+   +----+
            A          x       b

7.1 Determinant and Matrix Inverse

For a square matrix \(A\): - Determinant (det): A scalar reflecting the scaling factor of the linear transformation. If \(\det(A) = 0\), the matrix is singular and cannot be inverted. - Inverse (inv): \(A^{-1}\) such that \(A \cdot A^{-1} = I\) (Identity matrix).

Runnable Example

import numpy as np

A = np.array([
    [4.0, 7.0],
    [2.0, 6.0]
])

# 1. Determinant
det_A = np.linalg.det(A)
print(f"Determinant of A: {det_A:.2f}")  # 4*6 - 7*2 = 10.0

# 2. Matrix Inverse
A_inv = np.linalg.inv(A)
print("Inverse of A:\n", A_inv)

# Verification: A @ A_inv should equal Identity matrix (within floating point precision)
identity_check = A @ A_inv
print("A @ A_inv:\n", np.round(identity_check, 4))

7.2 Eigenvalues and Eigenvectors

Eigenvalues (\(\lambda\)) and eigenvectors (\(\vec{v}\)) satisfy:

\[A \vec{v} = \lambda \vec{v}\]

They represent directions along which a linear transformation acts merely by stretching or shrinking.

Runnable Example

M = np.array([
    [2.0, 1.0],
    [1.0, 2.0]
])

# Compute eigenvalues and eigenvectors
eigenvalues, eigenvectors = np.linalg.eig(M)

print("Eigenvalues:       ", eigenvalues)
print("Eigenvectors (columns):\n", eigenvectors)

# Verify for the first eigenvalue: M @ v0 == lambda0 * v0
v0 = eigenvectors[:, 0]
lambda0 = eigenvalues[0]
print("\nM @ v0:      ", M @ v0)
print("lambda0 * v0:", lambda0 * v0)

7.3 Solving Systems of Linear Equations

Given a system of linear equations \(A \vec{x} = \vec{b}\), find \(\vec{x}\).

Never compute \(\vec{x} = A^{-1} \vec{b}\) manually in scientific code! Inverting a matrix is slow and numerically unstable. Instead, always use np.linalg.solve(A, b), which uses LU decomposition:

\[\begin{cases} 2x + y - z = 8 \\ -3x - y + 2z = -11 \\ -2x + y + 2z = -3 \end{cases}\]

Runnable Example

# Coefficient matrix A
A = np.array([
    [ 2.0,  1.0, -1.0],
    [-3.0, -1.0,  2.0],
    [-2.0,  1.0,  2.0]
])

# Right-hand side vector b
b = np.array([8.0, -11.0, -3.0])

# Solve for x
solution = np.linalg.solve(A, b)
print("Solution [x, y, z]:", solution)  # [2., 3., -1.]

# Verify solution by computing A @ x
print("Verification (A @ x):", A @ solution)  # Should match b: [8., -11., -3.]

7.4 Types of Products: Dot, Matmul, and @

Python provides several ways to multiply arrays:

Operator / Function Purpose Example
* Elementwise multiplication A * B
np.dot(u, v) Vector dot product / Matrix product np.dot(u, v)
np.matmul(A, B) or @ Matrix multiplication A @ B
np.inner(u, v) Inner product of vectors np.inner(u, v)

Runnable Example

u = np.array([1, 2, 3])
v = np.array([4, 5, 6])

# Dot product of two 1D vectors: 1*4 + 2*5 + 3*6 = 32
dot_prod = np.dot(u, v)
print("Vector dot product:", dot_prod)

# Elementwise multiplication vs Matrix multiplication
X = np.array([[1, 2], [3, 4]])
Y = np.array([[2, 0], [1, 2]])

print("Elementwise (X * Y):\n", X * Y)
print("Matrix Product (X @ Y):\n", X @ Y)

Exercises and Mini-Lab: Electrical Circuit Analysis

Problem: Kirchhoff’s Mesh Current Method

Consider a two-loop DC circuit: - Loop 1 equation: \(12 I_1 - 4 I_2 = 18\) - Loop 2 equation: \(-4 I_1 + 10 I_2 = 0\)

Find the loop currents \(I_1\) and \(I_2\) in Amperes.

# Resistance matrix (Ohms)
R = np.array([
    [12.0, -4.0],
    [-4.0, 10.0]
])

# Voltage vector (Volts)
V = np.array([18.0, 0.0])

# Solve for currents [I1, I2]
I = np.linalg.solve(R, V)

print(f"Current I1: {I[0]:.3f} A")
print(f"Current I2: {I[1]:.3f} A")

# Check power dissipation: P = I^T * R * I
power = I @ R @ I
print(f"Total Circuit Power: {power:.3f} Watts")
