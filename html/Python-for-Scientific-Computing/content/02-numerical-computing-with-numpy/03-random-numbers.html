Chapter 6: Random Numbers in NumPy

From simulating thermal motion of molecules to modeling financial market fluctuations, randomness plays a vital role in scientific computing. NumPy features a state-of-the-art pseudo-random number generator that is both fast and statistically robust.

       [ Seed: 42 ] ──► [ Generator: default_rng() ]
                               │
            ┌──────────────────┼──────────────────┐
            ▼                  ▼                  ▼
      rng.random()       rng.integers()      rng.normal()
    (Floats 0.0-1.0)     (Dice / Coins)    (Bell Curve Gauss)

6.1 Creating a Modern Generator: default_rng()

Modern NumPy uses the default_rng() interface (based on the PCG64 algorithm), replacing the older legacy np.random.rand() API.

import numpy as np

# Instantiate a fresh random number generator
rng = np.random.default_rng()

6.2 Generating Random Floats and Integers

You can generate uniform floats, integers, or samples from scientific probability distributions:

Runnable Example

import numpy as np

rng = np.random.default_rng()

# 1. Random floats in range [0.0, 1.0)
uniform_floats = rng.random(size=5)
print("5 Uniform floats:\n", np.round(uniform_floats, 4))

# 2. Random integers in range [low, high)
# Simulating a standard 6-sided die (from 1 up to 7, exclusive)
dice_rolls = rng.integers(low=1, high=7, size=10)
print("10 Dice rolls:   ", dice_rolls)

# 3. Normally distributed (Gaussian) numbers: mean=0, std=1
bell_curve_samples = rng.normal(loc=0.0, scale=1.0, size=5)
print("5 Normal samples:", np.round(bell_curve_samples, 4))

6.3 Seeding for Reproducibility

Scientific experiments must be repeatable. If you publish a paper with a simulation, other scientists must be able to verify your results exactly.

Passing a fixed seed integer into default_rng(seed) guarantees that the exact same sequence of pseudo-random numbers is produced every single run.

# Run with seed=42
rng_a = np.random.default_rng(seed=42)
sample_a = rng_a.integers(1, 100, size=5)

# Run again with same seed=42
rng_b = np.random.default_rng(seed=42)
sample_b = rng_b.integers(1, 100, size=5)

print("Sample A:", sample_a)
print("Sample B:", sample_b)
print("Are they identical?", np.array_equal(sample_a, sample_b))  # True!

6.4 Scientific Simulations

1. Coin Toss Experiment (Law of Large Numbers)

Simulate flipping a fair coin 100,000 times and calculate the proportion of heads (1 = Head, 0 = Tail):

rng = np.random.default_rng(seed=101)
N = 100_000

# 0 or 1 with equal 50% probability
flips = rng.integers(0, 2, size=N)
heads_count = np.sum(flips == 1)
percentage = (heads_count / N) * 100.0

print(f"Total flips: {N:,}")
print(f"Heads:       {heads_count:,} ({percentage:.2f}%)")

2. The 1D Random Walk (Brownian Motion Model)

A particle starts at position \(x = 0\). At each time step, it steps either \(+1\) or \(-1\) with equal probability. We can model the entire walk instantaneously using cumsum() (cumulative sum):

Step:         0     1     2     3     4     5
Random delta: -    +1    -1    +1    +1    -1
Position x:   0    +1     0    +1    +2    +1
rng = np.random.default_rng(seed=2026)
steps = 10

# Generate +1 or -1 steps
# (rng.choice selects randomly from [-1, 1])
step_deltas = rng.choice([-1, 1], size=steps)

# Cumulative sum computes the position at every instant
positions = np.cumsum(step_deltas)

print("Step choices: ", step_deltas)
print("Trajectory:   ", positions)
print("Final displacement from origin:", positions[-1])
