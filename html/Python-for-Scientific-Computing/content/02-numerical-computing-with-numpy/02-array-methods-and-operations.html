Chapter 5: Array Methods, Operations, and Sorting

NumPy’s true power lies in vectorization: performing complex mathematical operations across thousands or millions of numbers in a single, elegant line of code—without writing a single for loop.

Loop Approach (Slow):
for i in range(len(a)):
    c[i] = a[i] + b[i]

Vectorized Approach (Fast):
c = a + b   <-- C-level SIMD acceleration under the hood!

5.1 Basic Methods: sum(), max(), min(), and T

You can call reduction methods either directly on the array object or via the np module:

Runnable Example

import numpy as np

arr = np.array([14.2, 8.5, 23.1, 19.4, 5.0])

print("Total sum:        ", arr.sum())
print("Maximum value:    ", arr.max())
print("Minimum value:    ", arr.min())
print("Mean value:       ", arr.mean())
print("Standard deviation:", arr.std())
print("Index of max value:", arr.argmax())

arr.std() divides by N, which is the population standard deviation. Lab reports usually want the sample standard deviation, arr.std(ddof=1), the same N − 1 divisor used for sample variance in Chapter 3.

Transposing a Matrix

To swap rows and columns, use the .T attribute or np.transpose():

A = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
print("Original matrix (2x3):\n", A)
print("Transposed matrix (3x2):\n", A.T)

5.2 Operating Over Axes: Rows vs Columns

In 2D arrays, reductions can be calculated across the entire matrix or along a specific axis:

                  axis = 1  (Across columns --> Row sums)
                  +-----+-----+-----+
                  |  1  |  2  |  3  | --> 6
                  +-----+-----+-----+
  axis = 0        |  4  |  5  |  6  | --> 15
  (Down rows)     +-----+-----+-----+
       |             |     |     |
       v             v     v     v
  Column sums:       5     7     9

Memory Rule for 2D Arrays: - axis = 0: Collapses rows (operates down each column). - axis = 1: Collapses columns (operates across each row).

Runnable Example

grades = np.array([
    [85, 90, 78],  # Student 0 [Exam 1, Exam 2, Exam 3]
    [72, 88, 91],  # Student 1
    [95, 92, 89],  # Student 2
    [60, 75, 70]   # Student 3
])

# Average grade for each student (across exams -> axis=1)
student_averages = grades.mean(axis=1)
print("Student averages (axis=1):", student_averages)

# Average grade for each exam (down students -> axis=0)
exam_averages = grades.mean(axis=0)
print("Exam averages (axis=0):   ", exam_averages)

5.3 Sorting Arrays

NumPy provides in-place sorting via .sort() and non-destructive sorting via np.sort():

Runnable Example

data = np.array([45, 12, 89, 33, 27])

# Non-destructive sort (returns a new array)
sorted_data = np.sort(data)
print("Sorted array:  ", sorted_data)
print("Original data: ", data)

# 2D sorting along axes
grid = np.array([[3, 1, 4], [1, 5, 9]])
print("Sorted along rows (axis=1):\n", np.sort(grid, axis=1))

# argsort: returns the indices that would sort the array
idx = np.argsort(data)
print("Indices of sorted items:", idx)

5.4 Elementwise Mathematical Functions

Standard mathematical functions in NumPy operate on every item in the array simultaneously:

\[\sin(\vec{x}), \quad e^{\vec{x}}, \quad \ln(\vec{x}), \quad \vec{x}^p\]

Runnable Example

angles_deg = np.array([0.0, 30.0, 45.0, 60.0, 90.0])

# Convert degrees to radians
angles_rad = np.radians(angles_deg)

# Elementwise trigonometric and exponential functions
sines = np.sin(angles_rad)
exponentials = np.exp(np.array([1, 2, 3]))
logs = np.log(exponentials)  # Natural logarithm

print("Angles (rad):", np.round(angles_rad, 3))
print("sin(theta):  ", np.round(sines, 3))
print("log(exp(x)): ", logs)  # [1. 2. 3.]

5.5 Vectorization vs Loops: Speed Benchmark

Why do scientists insist on vectorization? Because vectorized NumPy is written in optimized C/Fortran and runs 10x to 100x faster than pure Python loops!

import time

# Create 1 million numbers
N = 1_000_000
py_list = list(range(N))
np_arr = np.arange(N)

# 1. Pure Python loop
t0 = time.time()
py_result = [x ** 2 for x in py_list]
t_loop = time.time() - t0

# 2. Vectorized NumPy
t0 = time.time()
np_result = np_arr ** 2
t_vector = time.time() - t0

print(f"Python list loop:  {t_loop:.5f} seconds")
print(f"NumPy vectorized:  {t_vector:.5f} seconds")
print(f"NumPy is {t_loop / t_vector:.1f}x faster!")

5.6 Sequencing Arrays: np.vstack() and np.hstack()

You can combine existing arrays vertically (stack rows) or horizontally (stack columns):

  np.vstack([A, B]):              np.hstack([A, B]):
  +---+---+                       +---+---+---+---+
  | 1 | 2 |  (Row 0 of A)         | 1 | 2 | 5 | 6 |
  +---+---+                       +---+---+---+---+
  | 3 | 4 |  (Row 1 of A)         | 3 | 4 | 7 | 8 |
  +===+===+                       +---+---+---+---+
  | 5 | 6 |  (Row 0 of B)             A       B
  +---+---+
  | 7 | 8 |  (Row 1 of B)
  +---+---+

Runnable Example

a = np.array([[1, 2], [3, 4]])
b = np.array([[5, 6], [7, 8]])

# Vertical stacking: puts b underneath a
v_stacked = np.vstack([a, b])
print("Vertically stacked (4x2):\n", v_stacked)

# Horizontal stacking: puts b to the right of a
h_stacked = np.hstack([a, b])
print("Horizontally stacked (2x4):\n", h_stacked)
