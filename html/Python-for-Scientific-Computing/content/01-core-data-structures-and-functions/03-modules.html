Chapter 3: Modules

A module is simply a Python file (.py) containing function definitions, constants, and variables. Modules allow you to organize code logically across multiple files, share tools across different lab assignments, and tap into Python’s vast ecosystem of pre-written libraries.

+--------------------------------------------+
| main.py                                    |
|   import mytools                           |
|   out = mytools.calculate_stats(data)      |
+--------------------------------------------+
| mytools.py                                 |
|   def calculate_stats(data):               |
|       return mean, std_dev                 |
+--------------------------------------------+

3.1 Importing Modules: The Three Syntax Forms

Python provides three ways to bring code from a module into your script:

1. Full import:
   import math
   math.sqrt(16)

2. Alias import (standard in data science):
   import numpy as np
   np.zeros(5)

3. Direct member import:
   from math import sqrt, pi
   sqrt(16)

Runnable Example

# Style 1: Standard import
import math
print("Sine of pi/2:", math.sin(math.pi / 2))

# Style 2: Import with an alias (shorthand)
import math as m
print("Cosine of 0: ", m.cos(0))

# Style 3: Selective import (import specific functions directly)
from math import sqrt, exp
print("Square root: ", sqrt(25.0))
print("Exponential: ", exp(1.0))

College Tip: Avoid from math import * (wildcard imports)! It pollutes your namespace with hundreds of names and can overwrite your own variables by accident.

3.2 Importing Part of a Module

When a module is large or hierarchical (e.g., matplotlib.pyplot or scipy.optimize), you can import just the submodule you need:

# Import only the sub-package
import matplotlib.pyplot as plt

# Or specific constants
from math import pi, e
print(f"pi = {pi:.4f}, e = {e:.4f}")

3.3 Module-Name Rules and Abstraction

Modules enforce namespace isolation. If you define your own variable named pi = 3.14 and import math, you can access both without collision:

pi = 3.14           # Your rough local approximation
import math         # Official math module

print("My local pi:    ", pi)
print("Math module pi: ", math.pi)

3.4 The Built-in math Module: Common Functions

The standard library includes math for scalar calculations. Here are the most frequently used scientific functions:

Function Description Example Result
math.sqrt(x) Square root \(\sqrt{x}\) math.sqrt(9) 3.0
math.pow(x, y) \(x^y\) math.pow(2, 3) 8.0
math.sin(x), cos(x) Trig functions (radians!) math.sin(math.pi/2) 1.0
math.radians(deg) Degrees to radians math.radians(180) 3.14159...
math.degrees(rad) Radians to degrees math.degrees(math.pi) 180.0
math.log(x) Natural logarithm (\(\ln x\)) math.log(math.e) 1.0
math.log10(x) Base-10 logarithm math.log10(100) 2.0
math.ceil(x) Round up to integer math.ceil(4.2) 5
math.floor(x) Round down to integer math.floor(4.8) 4

3.5 Module Structure: if __name__ == "__main__"

When Python runs a file directly, it sets a special built-in variable __name__ to "__main__". But when that file is imported by another script, __name__ is set to the file’s actual module name.

We use this construct to include testing code in a module that only runs when the module file is executed on its own, not when it is imported elsewhere!

  Run the file directly:  __name__ is "__main__"  --> tests run
  Import the file:         __name__ is "mytools"   --> tests are skipped

3.6 Creating Your Own User-Defined Module

Let us create a reusable module for college physics formulas.

Step 1: Create physics_tools.py

In Spyder, create a new file named physics_tools.py in your working directory:

# physics_tools.py - Reusable physics utility functions
import math

GRAVITY = 9.80665  # m/s^2 on Earth surface

def free_fall_distance(time):
    """Calculate distance fallen under gravity: d = 0.5 * g * t^2"""
    return 0.5 * GRAVITY * (time ** 2)

def pendulum_period(length):
    """Calculate period of simple pendulum: T = 2 * pi * sqrt(L / g)"""
    return 2.0 * math.pi * math.sqrt(length / GRAVITY)

# Self-test block: runs ONLY if you run physics_tools.py directly
if __name__ == "__main__":
    print("Testing physics_tools module:")
    print("Drop distance in 3 seconds: ", free_fall_distance(3.0), "m")
    print("Period of 1m pendulum:      ", pendulum_period(1.0), "s")

Step 2: Import It in a Separate Script lab_experiment.py

Now create another file in the same folder:

# lab_experiment.py
import physics_tools as phys

drop_time = 2.5
dist = phys.free_fall_distance(drop_time)
print(f"Object fell {dist:.2f} meters in {drop_time} seconds.")

When you run lab_experiment.py, the test printouts from physics_tools.py will not appear!

3.7 The Module Search Path & Spyder Import Errors

When you type import mytools, Python searches for mytools.py in this order: 1. The current working directory (where your script or Spyder console is pointed). 2. The installed standard library and Conda environment packages. 3. Folders listed in sys.path.

  If you see:  ModuleNotFoundError: No module named 'physics_tools'
  
  Cause:  Spyder's working directory is not set to the folder where 
          physics_tools.py is saved!
  Fix:    Click the folder icon in Spyder's top-right toolbar and select 
          your project folder, or run:
          import os; os.chdir("/path/to/your/folder")

Exercises and Mini-Lab

Exercise: Personal Statistics Module (my_stats.py)

Create a module named my_stats.py with three functions: mean(), variance(), and standard_deviation().

# my_stats.py
import math

def mean(data):
    """Compute arithmetic average."""
    if not data:
        return 0.0
    return sum(data) / len(data)

def variance(data):
    """Compute sample variance: sum((x - mean)^2) / (N - 1)"""
    if len(data) < 2:
        return 0.0
    m = mean(data)
    sq_diff = sum((x - m) ** 2 for x in data)
    return sq_diff / (len(data) - 1)

def standard_deviation(data):
    """Compute sample standard deviation."""
    return math.sqrt(variance(data))

if __name__ == "__main__":
    test_scores = [85, 92, 78, 90, 88]
    print("Test mean:  ", mean(test_scores))
    print("Test std-dev:", standard_deviation(test_scores))
