Chapter 2: Functions

As your programs grow, copy-pasting code leads to bugs, repetition, and headaches. Functions are self-contained mini-programs that accept inputs, perform specific calculations, and return results. They form the building blocks of clean scientific code.

                  +-------------------------------+
   Input data --->|       Function Black Box      +---> Output Result
   (Arguments)    |   - Takes inputs              |     (Return value)
                  |   - Computes formula          |
                  |   - Hides internal complexity |
                  +-------------------------------+

2.1 Why Functions?

In science and engineering, functions provide three essential advantages: 1. Repeatability: Write the code once and use it thousands of times with different inputs. 2. Decomposition: Break a massive, confusing problem into small, manageable, testable steps. 3. Abstraction: You don’t need to know how math.sqrt() computes a square root internally to use it effectively.

2.2 Defining a Function and return

A function is defined with the def keyword, followed by the function name, parentheses (), and a colon :. The indented block is the body. The return statement sends a result back to the caller and immediately terminates execution of the function.

       def function_name(param1, param2):
           # Function body (indented)
           result = param1 + param2
           return result   <-- Sends value back and exits

Runnable Example

def kinetic_energy(mass, velocity):
    """Calculate kinetic energy in Joules: KE = 0.5 * m * v^2"""
    ke = 0.5 * mass * (velocity ** 2)
    return ke

# Calling the function
car_ke = kinetic_energy(1200.0, 25.0)  # 1200 kg car at 25 m/s
print("Kinetic energy:", car_ke, "Joules")

If a function does not have a return statement (or reaches the end without one), it implicitly returns None.

2.3 Formal vs Actual Parameters

  • Formal Parameters: The variable names listed in the function definition (the placeholders).
  • Actual Parameters (Arguments): The real values or variables passed into the function when you call it.
  # formal parameters: voltage, resistance
  def ohms_law(voltage, resistance):
      return voltage / resistance

  # actual arguments: 12.0 and 4.0
  current = ohms_law(12.0, 4.0)

2.4 Positional, Keyword Arguments, and Defaults

Python gives you flexibility in how arguments are passed: - Positional arguments: Matched by position (first to first, second to second). - Keyword arguments: Explicitly matched by name (param=value), regardless of order. - Default arguments: Provide fallback values if the caller omits them.

Runnable Example

def radioactive_decay(initial_amount, time, half_life=5.0):
    """
    Computes remaining substance: N(t) = N0 * (0.5)^(t / half_life).
    half_life defaults to 5.0 time units if omitted.
    """
    remaining = initial_amount * (0.5 ** (time / half_life))
    return remaining

# 1. Positional call using default half_life (5.0)
print(
    "Amount left after 10s (default half-life):",
    radioactive_decay(100.0, 10.0),
)

# 2. Positional call overriding half_life
print(
    "Amount left after 10s (half-life=2.0):",
    radioactive_decay(100.0, 10.0, 2.0),
)

# 3. Keyword call (order does not matter)
print("Keyword call:", radioactive_decay(
    time=15.0, initial_amount=80.0, half_life=3.0))

2.5 The * Operator: *args and Unpacking

When you do not know in advance how many arguments will be passed, use *args. The * packs multiple positional arguments into a single tuple.

  Call: average(10, 20, 30, 40)
             |   |   |   |
             v   v   v   v
  Function receives args = (10, 20, 30, 40)

Runnable Example

def compute_mean(*numbers):
    """Compute the arithmetic mean of any number of inputs."""
    if len(numbers) == 0:
        return 0.0
    total = sum(numbers)
    return total / len(numbers)

print("Mean of 3 values:", compute_mean(10, 20, 30))
print("Mean of 5 values:", compute_mean(2.5, 3.5, 4.0, 1.0, 9.0))

# Unpacking a list into arguments using *
sample_data = [12.0, 15.5, 18.2, 14.1]
print("Mean from unpacked list:", compute_mean(*sample_data))

2.6 Lambda Functions (Anonymous Functions)

A lambda is a small, one-line function defined without a name:

\[\text{Syntax:} \quad \textbf{lambda} \quad \text{arguments}: \quad \text{expression}\]

Runnable Example

# Standard function vs Lambda function
def standard_square(x):
    return x ** 2

lambda_square = lambda x: x ** 2

print("Standard:", standard_square(5))  # 25
print("Lambda:  ", lambda_square(5))    # 25

# Practical use: sorting a list of (x, y) coordinates by y-value
points = [(1, 9), (4, 2), (3, 7), (8, 1)]
sorted_by_y = sorted(points, key=lambda p: p[1])
print("Points sorted by y-coordinate:", sorted_by_y)

2.7 Variable Scope and the Stack Frame

Variables created inside a function are local to that function. They live inside the function’s stack frame and are destroyed when the function finishes executing.

  Global Scope:
  +---------------------------------+
  | x = 100                         |
  |                                 |
  |   Stack Frame: calculate(a=5)   |
  |   +-------------------------+   |
  |   | a = 5                   |   |
  |   | temp = a * 2 = 10       |   |
  |   +-------------------------+   |
  |   (Destroyed after return!)     |
  +---------------------------------+

Runnable Example

x = 100  # Global variable

def calculate(a):
    temp = a * 2  # Local variable
    print("Inside calculate(): temp =", temp, "and global x =", x)
    return temp

result = calculate(5)
print("Result:", result)

# Trying to access 'temp' here will cause a NameError:
# print(temp)  # Error: name 'temp' is not defined!

2.8 Docstrings and Spyder’s Help Pane

A docstring is a multi-line string placed immediately below the function header. It documents what the function does, its parameters, and what it returns.

def celsius_to_kelvin(temp_c):
    """
    Convert temperature from degrees Celsius to Kelvin.

    Parameters
    ----------
    temp_c : float
        Temperature in Celsius (°C).

    Returns
    -------
    float
        Temperature in Kelvin (K).
    """
    return temp_c + 273.15
Spyder Tip: Interactive Help

In Spyder, type celsius_to_kelvin( in the Editor or Console and press Ctrl + I (Cmd + I on Mac). The Help Pane will automatically render your docstring beautifully formatted!

2.9 The global Keyword

To modify a global variable from inside a function, Python requires the global keyword.

Advice for Beginners: Use global sparingly! Functions that modify global variables are harder to test and debug. Prefer returning values instead.

Runnable Example

total_samples = 0  # Global counter

def record_measurement(value):
    global total_samples
    total_samples += 1
    print(f"Sample #{total_samples} recorded: {value} V")

record_measurement(3.3)
record_measurement(3.4)
print("Total samples logged:", total_samples)  # 2

2.10 Recursion: Base Case and Call Stack

A recursive function is a function that calls itself to solve a smaller version of the problem. Every recursive function must have: 1. Base Case: A stopping condition that returns directly without further recursion. 2. Recursive Step: Where the function calls itself with a reduced input.

  factorial(3)
    +-- 3 * factorial(2)
          +-- 2 * factorial(1)
                +-- 1  (Base case: returns 1)

Runnable Example: Factorial

def factorial(n):
    """Compute n! recursively. n is a non-negative integer."""
    # Base case. Both 0! and 1! are 1.
    if n == 0 or n == 1:
        return 1
    # Recursive case
    return n * factorial(n - 1)

print("5! =", factorial(5))  # 5 * 4 * 3 * 2 * 1 = 120

A negative n never hits that base case. Python then stops the calls with RecursionError.

2.11 Functions as First-Class Objects

In Python, functions are objects! You can assign them to variables, store them in lists, and pass them as arguments to other functions (often called higher-order functions).

Runnable Example

import math

def evaluate_at_points(func, points):
    """Applies a mathematical function 'func' to a list of x values."""
    return [func(x) for x in points]

x_values = [0.0, math.pi / 4, math.pi / 2, math.pi]

# Pass math.sin as an argument
sin_values = evaluate_at_points(math.sin, x_values)
print("Sin values:", [round(v, 4) for v in sin_values])

# Pass a custom lambda as an argument
squared_values = evaluate_at_points(lambda x: x**2, [1, 2, 3, 4, 5])
print("Squares:   ", squared_values)

Exercise 1: Fibonacci Sequence (Iterative vs Recursive)

# 1. Recursive Fibonacci
def fib_recursive(n):
    if n <= 0:
        return 0
    elif n == 1:
        return 1
    return fib_recursive(n - 1) + fib_recursive(n - 2)

# 2. Iterative Fibonacci (much faster for large n!)
def fib_iterative(n):
    if n <= 0:
        return 0
    a, b = 0, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b

print("10th Fibonacci (recursive):", fib_recursive(10))  # 55
print("10th Fibonacci (iterative):", fib_iterative(10))  # 55

Mini-Lab: Mathematical Function Table Helper

Write a function generate_function_table(func, name, x_start, x_end, steps) that prints a clean text table:

def generate_function_table(func, name, x_start, x_end, steps):
    step_size = (x_end - x_start) / (steps - 1)
    print(f"--- Table for {name} ---")
    print(f"{'x':>10} | {'f(x)':>12}")
    print("-" * 25)
    for i in range(steps):
        x = x_start + i * step_size
        y = func(x)
        print(f"{x:10.4f} | {y:12.4f}")

# Test with a cubic polynomial: f(x) = x^3 - 2x + 1
poly = lambda x: x**3 - 2*x + 1
generate_function_table(poly, "x^3 - 2x + 1", -2.0, 2.0, 9)
