First-Class Functions

After this page you can pass a function into sorted, return a small function, and know when a lambda is enough.

Functions are objects. You can pass them, return them, put them in a list, and attach attributes. That is what “first-class” means: a function is a value, like 20 or "ada".

Every python block below is a complete file. The first line is the filename. Save it and run uv run python that_file.py.

Mental model

  def greet(name): …
        |
        v
  name “greet” ──►  function object
                         |
                         +-- __name__  "greet"
                         +-- you can call it: greet("ada")
                         +-- you can pass it: apply(greet, "ada")

greet is just a name. other = greet is two names on one function.

Pass a function

# apply_twice.py
def apply_twice(fn, x):
    return fn(fn(x))


def inc(n):
    return n + 1


if __name__ == "__main__":
    print(apply_twice(inc, 3))
    print(apply_twice(str.upper, "py"))

Expected:

5
PY

You pass inc, not inc(). inc is the function; inc() would call it with no arguments and pass the result.

sorted(key=…), max(key=…), and min(key=…) are the stdlib version of this idea.

# sort_by_len.py
words = ["banana", "fig", "apple"]
print(sorted(words))
print(sorted(words, key=len))

Expected:

['apple', 'banana', 'fig']
['fig', 'apple', 'banana']

key=len means “compare items by len(item).” You pass the function len.

Worked example: sort by the number after =

# sort_ids.py
rows = ["id=12", "id=3", "id=100"]


def id_number(row):
    return int(row.split("=")[1])


if __name__ == "__main__":
    print(sorted(rows, key=id_number))
    print(sorted(rows))

Expected:

['id=3', 'id=12', 'id=100']
['id=100', 'id=12', 'id=3']

Without key, "id=100" sorts before "id=12" because "1" < "3" as text.

Return a function

# multiply_by.py
def multiply_by(k):
    def inner(n):
        return n * k
    return inner


if __name__ == "__main__":
    triple = multiply_by(3)
    print(triple(4))
    print(multiply_by(10)(2))

Expected:

12
20

multiply_by(3) returns a function. That function remembers k = 3 (a closure — see Scope).

lambda

# sort_by_last.py
words = ["banana", "fig", "apple"]
print(sorted(words, key=lambda w: w[-1]))

Expected:

['banana', 'apple', 'fig']

A lambda is an anonymous function whose body is one expression. The line above sorts by last letter (a, e, g).

# last_char.py
def last_char(w):
    return w[-1]


if __name__ == "__main__":
    also = lambda w: w[-1]  # legal, but a def is clearer if you want a name
    print(last_char("fig"), also("fig"))

Expected:

g g

If you want a name, two lines, or a docstring, use def.

Small higher-order tools

# map_filter.py
print(list(map(str.upper, ["a", "b"])))
print(list(filter(lambda n: n % 2 == 0, range(6))))
print([s.upper() for s in ["a", "b"]])
print([n for n in range(6) if n % 2 == 0])

Expected:

['A', 'B']
[0, 2, 4]
['A', 'B']
[0, 2, 4]

A comprehension is often clearer than map/filter. This book defaults to comprehensions.

Python + CS

Once functions are values, you can write combinators (functions that take functions) and strategies (pass the step that varies). sorted(..., key=…) is the everyday case: the sort algorithm stays put; what to compare is the argument.

Pitfalls

sorted(xs, key=len()) calls len and passes its result. Pass len.

Worked example: the late-binding loop

A lambda that closes over a loop variable i and is called later sees the last i. Bind it as a default: lambda i=i: i.

# late_binding.py
fns = []
for i in range(3):
    fns.append(lambda: i)
print([fn() for fn in fns])

fns = []
for i in range(3):
    fns.append(lambda i=i: i)
print([fn() for fn in fns])

Expected:

[2, 2, 2]
[0, 1, 2]

Default arguments are bound when the lambda is created. That is the usual fix.

callable(x) is the test for “can I call this?”. type(x) is function is the wrong test (built-ins such as len are a different type).
