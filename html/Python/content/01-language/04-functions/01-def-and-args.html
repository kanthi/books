def and Arguments

After this page you can write a function with defaults, call it with names or positions, and avoid the mutable-default trap.

A function is a named computation. def creates a function object and binds it to a name.

Every python block below is a complete file. The first line is the filename. Save it and run uv run python that_file.py.

Mental model

  call  c_to_f(20)
           |
           v
  new frame: celsius → 20
           |
           v
  body runs; return value comes back
           |
           v
  frame discarded

Each call gets its own frame — its own set of names. Two calls of c_to_f do not share a celsius. Internals draws this with real objects; you only need “each call is a fresh workspace” for now.

Minimal example

# c_to_f.py
def c_to_f(celsius):
    """Convert Celsius to Fahrenheit."""
    return celsius * 9 / 5 + 32


if __name__ == "__main__":
    print(c_to_f(0), c_to_f(100))
uv run python c_to_f.py

Expected:

32.0 212.0

The string under def is a docstring. help(c_to_f) in the REPL shows it. Write one sentence for anything you will still be using next week.

# greet.py
def greet(name):
    return f"hello, {name}"


if __name__ == "__main__":
    print(greet("Ada"))
    print(greet)

Expected (the second line’s 0x… will differ):

hello, Ada
<function greet at 0x...>

greet without () is the function object. greet("Ada") is a call.

Kinds of arguments

# clip.py
def clip(n, lo=0, hi=100):
    return max(lo, min(n, hi))


if __name__ == "__main__":
    print(clip(150))
    print(clip(150, hi=80))
    print(clip(n=-5, lo=-10, hi=10))

Expected:

100
80
-5
Kind Example Meaning
Positional clip(150) first argument fills n
Keyword clip(150, hi=80) fill hi by name; skip lo
Default lo=0 used when the caller omits it

You can mix them: positional first, then keywords. clip(hi=80, 150) is a SyntaxError.

Worked example: defaults are bound once

Defaults are bound once, when def runs — not each call. Never use a mutable default (def f(xs=[])). Use None and create a new list in the body.

# mutable_default.py
def broken(item, bucket=[]):
    bucket.append(item)
    return bucket


def fixed(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket


if __name__ == "__main__":
    print("broken", broken("a"), broken("b"))
    print("fixed ", fixed("a"), fixed("b"))

Expected:

broken ['a', 'b'] ['a', 'b']
fixed  ['a'] ['b']

broken("a") and broken("b") print the same list twice at the end of the first line — that is the bug.

* and / (preview)

# connect.py
def connect(host, port, /, *, timeout=30):
    return host, port, timeout


if __name__ == "__main__":
    print(connect("localhost", 8000))
    print(connect("localhost", 8000, timeout=5))
    # print(connect(host="localhost", port=8000))  # TypeError: positional-only

Expected:

('localhost', 8000, 30)
('localhost', 8000, 5)

Parameters before / are positional-only (you cannot write host=). Parameters after * are keyword-only (you must write timeout=). You will see this in stdlib signatures (help(max)). You rarely need it in Path A.

Arbitrary arguments

# extra_args.py
def total(*nums):
    return sum(nums)


def label(**meta):
    return meta


def show(*args, **kwargs):
    print("args", args)
    print("kwargs", kwargs)


if __name__ == "__main__":
    print(total(1, 2, 3))
    print(label(src="lab", n=2))
    show(1, 2, color="red")

Expected:

6
{'src': 'lab', 'n': 2}
args (1, 2)
kwargs {'color': 'red'}

*nums is a tuple of extra positional args. **meta is a dict of extra keywords.

Return

  • return value exits immediately and sends value back.
  • A bare return or falling off the end returns None.
  • You can return several values: return a, b — that is a tuple. Unpack at the call: x, y = f().
# min_max.py
def min_max(xs):
    return min(xs), max(xs)


if __name__ == "__main__":
    lo, hi = min_max([3, 1, 4])
    print(lo, hi)

Expected:

1 4

Python + CS

Functions are the unit of abstraction: hide a recipe behind a name so the caller does not have to see the steps. Recursion (a function calling itself) can wait until frames feel comfortable — try this when you are ready:

# factorial.py
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)


if __name__ == "__main__":
    print(factorial(5))
    print(factorial(0))

Expected:

120
1

Pitfalls

  • def f(xs=[]) — one list shared across calls (see mutable_default.py).
  • Forgetting return and wondering why the function “returns nothing” (None).
  • Mutating a list or dict the caller passed in, unless the name says so (sort vs sorted).
  • clip(150, 80) sets lo=80, not hi. Use clip(150, hi=80) when you skip a middle parameter.

Exercises

  1. Copy clip.py to clamp.py, rename the function, and print the three edges (below, inside, above).
  2. Write mean.py with mean(*nums) that returns None if there are no arguments, otherwise the average. Print mean(1, 2, 3) and mean().
  3. Run mutable_default.py. Then add a third broken("c") call and watch the list grow.
