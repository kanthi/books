Why Python Exists

After this page you will know what Python is for, who uses it, and what it is not — so the rest of Path A has a reason.

Python exists so that people can write clear programs quickly on a wide range of machines, then grow those programs without throwing the language away.

You do not need another book to start. A terminal, an editor, and the next section (install) are enough.

Mental model

  human idea
       |
       v
  readable source     ← this is the product Python optimizes
       |
       v
  CPython (or another implementation)
       |
       v
  your OS, files, network, GPU, browser, robot, …

Guido van Rossum started Python in the late 1980s at CWI in the Netherlands. He wanted a successor to ABC that was practical for real work: extensible in C, good at text and glue, and pleasant to read. The name is from Monty Python, not the snake.

The language succeeded because it sat in a gap:

Pressure What Python offered
Scripts were too small Modules, packages, a huge standard library
C / C++ were too slow to write A high-level language that still calls C
Java / C# needed a heavy runtime story A single file and a REPL
Shell was great at glue, weak at data One language for glue and data structures
Research needed a notebook The same language in a REPL, a script, and a service

What Python was designed to do

1. Read well

Python uses indentation instead of braces. That is not a gimmick: it forces a single visual structure so a file looks like the block tree the interpreter uses.

# greet.py
def greet(name):
    if name:
        return f"hello, {name}"
    return "hello"


if __name__ == "__main__":
    print(greet("Ada"))
    print(greet(""))
uv run python greet.py

Expected:

hello, Ada
hello

There is one obvious layout: the indent is the block. Tools such as Ruff (a formatter and linter you will meet in Project layout) lock the rest of the style down so reviews talk about behavior, not spaces.

2. Stretch from a one-liner to a system

The same language runs:

  • a 5-line rename script
  • a pandas notebook
  • a FastAPI service
  • a Nornir run across a lab
  • a training loop on a GPU

You will change libraries and architecture. You rarely need a second language for the next job.

3. Call out to faster code

Python is often the control plane. NumPy, PyTorch, database drivers, and most OS bindings are C, C++, Rust, or Fortran underneath. That is why a slow-looking language dominates scientific computing and AI: the hot loops are not in Python bytecode.

Who uses it (and why that matters to you)

Python is the default glue in:

  • Science and data — NumPy, pandas, Jupyter
  • Machine learning and AI — sklearn, PyTorch, JAX, LLM clients
  • Web APIs — FastAPI, Django
  • Automation — Ansible (Python under the hood), cloud SDKs, Netmiko
  • Education — CS50P, MIT 6.100L, almost every intro CS course

If you learn the language and how CPython runs it, those domains share one mental model.

What Python is not

  • Not the fastest CPU language. For a tight inner loop, measure, then move work to NumPy, a native extension, or another language.
  • Not a single-binary culture. You ship an environment (uv lockfile or a container), not one static file.
  • Not “only scripting.” That reputation is twenty years out of date. Production services, models, and operators all run Python.
  • Not one implementation. CPython is what this book means by “Python” unless a page says PyPy, MicroPython, or IronPython.

Python + CS

A language is a notation plus a machine. The notation is what you type (def, if, a list). The machine is the program that carries it out (CPython — the next page). Part 01 teaches the notation first. Internals teaches the machine, after you can write a small script.

Exercises

  1. Write three tasks you personally want Python to do (one script, one data task, one service or automation). Keep the list; Path A should hit at least one.
  2. Name one job you would not start in Python, and why (performance, binary distribution, browser, kernel, …).
  3. Read the first page of the official tutorial and list two claims that match this chapter and one that surprised you.
