Unpacking

After this page you can split a pair into names, grab “the rest” with *, and pass a list or dict into a function with * / **.

Unpacking assigns parts of a structure to names. It is how Python spells “this sequence has this shape.”

Every python block below is a complete file. The first line is the filename. Save it and run uv run python that_file.py.

Mental model

  left          right
  a, b     =    (1, 2)
  a, *rest =    [1, 2, 3]
  {k: v}   in   a dict merge or match

match (Control flow) is unpacking plus branching.

Sequences

# unpack_seq.py
x, y = (2, 3)
head, *mid, tail = [1, 2, 3, 4]
first, second = "ab"
print(x, y)
print(head, mid, tail)
print(first, second)

Expected:

2 3
1 [2, 3] 4
a b

The number of names must match, unless you use *. Too many or too few values: ValueError.

# unpack_error.py
try:
    a, b = [1, 2, 3]
except ValueError as err:
    print(type(err).__name__, err)

Expected:

ValueError too many values to unpack (expected 2)

*mid soaks up whatever is left. It is always a list, even if you unpacked a tuple.

Worked example: first and last name

# names.py
first, last = "ada lovelace".split()
print(first, last)

first, *rest = "ada king lovelace".split()
print(first, rest)

Expected:

ada lovelace
ada ['king', 'lovelace']

This fails (on purpose) if the first line’s string has one word or three. That is often what you want.

Swapping and returning

# swap_bounds.py
a, b = "tea", "coffee"
a, b = b, a
print(a, b)


def bounds(xs):
    return min(xs), max(xs)


if __name__ == "__main__":
    lo, hi = bounds([3, 1, 4])
    print(lo, hi)

Expected:

coffee tea
1 4

The right-hand side is evaluated fully, then the left is bound. That is why swap works without a temporary.

Stars in calls

# star_call.py
def clip(n, lo, hi):
    return max(lo, min(n, hi))


if __name__ == "__main__":
    args = (150, 0, 100)
    print(clip(*args))
    opts = {"n": 150, "lo": 0, "hi": 100}
    print(clip(**opts))
    try:
        clip(*[150, 0])
    except TypeError as err:
        print(type(err).__name__, err)

Expected:

100
100
TypeError clip() missing 1 required positional argument: 'hi'

* expands a sequence into positional arguments. ** expands a dict into keywords. The keys must match parameter names.

Merging (3.9+)

# merge_dicts.py
defaults = {"host": "localhost", "port": 8000}
user = {"port": 9000}
print("right wins", defaults | user)
print("left wins ", user | defaults)
print("old spell ", {**defaults, **user})
print("lists     ", [1, 2] + [3], [*[1, 2], *[3]])

Expected:

right wins {'host': 'localhost', 'port': 9000}
left wins  {'port': 8000, 'host': 'localhost'}
old spell  {'host': 'localhost', 'port': 9000}
lists      [1, 2, 3] [1, 2, 3]

| on dicts is a merge. The right-hand dict wins on conflicts. {**defaults, **user} is the older spelling. For lists, [*xs, *ys] or xs + ys.

Nested

# nested.py
pt, color = ((2, 3), "red")
(x, y), color = ((2, 3), "red")
print(pt, color)
print(x, y, color)

Expected:

(2, 3) red
2 3 red

If the nesting is deeper than one level, match or a named tuple is usually kinder.

Pitfalls

# unpack_dict.py
d = {"x": 1, "y": 2}
a, b = d
print("keys", a, b)
(ka, va), (kb, vb) = d.items()
print("pairs", ka, va, kb, vb)

parts = "ada".split()
try:
    first, last = parts
except ValueError as err:
    print(type(err).__name__, err)

Expected:

keys x y
pairs x 1 y 2
ValueError not enough values to unpack (expected 2, got 1)
  • *rest is always a list, even if you unpacked a tuple.
  • def f(*args, **kwargs) then f(*args, **kwargs) is the usual wrap; missing * / ** passes one tuple and one dict as two positional args.
  • Guard with if len(parts) == 2 when input is messy.

Exercises

  1. Run names.py. Then try "ada" alone and read the ValueError.
  2. Write tail.py using _, *rest that works for one or more items. Print what an empty list does.
  3. Run merge_dicts.py and change the two dicts so three keys overlap. Confirm which side wins.
