Bayes with odds: prior odds, likelihood ratios, posterior probability

After reading this page, you will be able to convert probabilities to odds and back, update beliefs using Bayes’ theorem in odds form (\(O_{\text{posterior}} = O_{\text{prior}} \times \text{LR}\)), apply likelihood ratios to sequential evidence, evaluate the assumption of naive independence, and explain why base-rate neglect leads to misinterpreting diagnostic tests.

Thesis

Bayes’ theorem is often presented in standard probability notation:

\[ P(A \mid B) = \frac{P(B \mid A) P(A)}{P(B)} \]

While mathematically exact, computing the denominator \(P(B) = P(B \mid A)P(A) + P(B \mid \neg A)P(\neg A)\) requires updating normalizers every time new evidence is gathered. Expressing Bayes’ theorem in odds form eliminates the denominator entirely, converting probability updates into straightforward multiplication:

\[ \text{Posterior Odds} = \text{Prior Odds} \times \text{Likelihood Ratio} \]

This odds formulation decouples the prior probability of a state from the diagnostic power of the test. It provides an intuitive framework for sequential Bayesian updating, exposing how low base rates dominate rare-event testing even when test sensitivity and specificity are high.

Mental model

To work fluently with Bayesian updates, it is essential to translate between probability space \([0, 1]\) and odds space \([0, \infty)\).

Term Formula / Definition Intuition / Role
Probability (\(p\)) \(\frac{\text{favorable outcomes}}{\text{total outcomes}}\) Standard measure bounded in \([0, 1]\).
Odds (\(o\)) \(\frac{p}{1 - p} = \frac{\text{favorable outcomes}}{\text{unfavorable outcomes}}\) Ratio of event occurring to event not occurring; bounded in \([0, \infty)\).
Likelihood Ratio (\(\text{LR}\)) \(\frac{P(\text{Evidence} \mid \text{Condition})}{P(\text{Evidence} \mid \neg \text{Condition})} = \frac{\text{TPR}}{\text{FPR}}\) Diagnostic power of evidence; independent of background prevalence.
Base Rate (\(P(\text{Condition})\)) Unconditional prior probability in the target population Starting weight of the condition before testing.

The likelihood ratio \(\text{LR} = \frac{\text{Sensitivity}}{1 - \text{Specificity}} = \frac{\text{True Positive Rate}}{\text{False Positive Rate}}\) encapsulates the test’s discriminative strength: - \(\text{LR} > 1\): Evidence favors the hypothesis (increases odds). - \(\text{LR} = 1\): Evidence is completely uninformative (odds remain unchanged). - \(0 \le \text{LR} < 1\): Evidence disfavors the hypothesis (decreases odds).

Base-rate neglect

Base-rate neglect occurs when an observer evaluates a diagnostic result based solely on test accuracy (sensitivity and specificity) while ignoring the underlying prevalence (prior probability) of the condition.

For instance, consider a disease with a 1% prevalence (\(p = 0.01\)). A test with 99% sensitivity (\(\text{TPR} = 0.99\)) and 99% specificity (\(\text{FPR} = 0.01\)) sounds highly reliable. However, in a population of 10,000 individuals: - 100 people have the disease, and 99 test positive. - 9,900 people do not have the disease, but 1% (99 people) test positive.

Out of 198 positive test results, only 99 actually have the disease. The true posterior probability following a single positive test is exactly 50%, not 99%.

Sequential updating and naive independence

When multiple diagnostic tests or pieces of evidence are observed sequentially, the posterior odds after the first evidence become the prior odds for the second evidence:

\[ \text{Odds}_{\text{final}} = \text{Odds}_{\text{prior}} \times \text{LR}_1 \times \text{LR}_2 \times \dots \times \text{LR}_n \]

This sequential update assumes conditional independence (often called the naive independence assumption):

\[ P(E_1, E_2 \mid C) = P(E_1 \mid C) P(E_2 \mid C) \]

If two positive test results stem from correlated mechanisms (e.g., repeating the same laboratory assay using the same sample batch), conditional independence fails. Assuming independence when features are correlated overestimates confidence, driving posterior odds artificially high.

Python implementation: Medical test simulator

The following script implements probability-to-odds conversions, updates prior odds via likelihood ratios, and demonstrates a two-stage diagnostic test scenario without external libraries.

"""Posterior odds from prior odds and likelihood ratio."""

def posterior_odds(prior_odds: float, lr: float) -> float:
    return prior_odds * lr

def odds_to_prob(o: float) -> float:
    return o / (1.0 + o)

def prob_to_odds(p: float) -> float:
    return p / (1.0 - p)

# Medical test: prevalence 1%, sensitivity 99%, false positive 1%
prior = prob_to_odds(0.01)
lr = 0.99 / 0.01
post = posterior_odds(prior, lr)
print(f"prior_odds={prior:.6f}")
print(f"likelihood_ratio={lr:.6f}")
print(f"posterior_odds={post:.6f}")
print(f"posterior_prob={odds_to_prob(post):.6f}")
# Two independent positive tests (same LR, naive independence)
post2 = posterior_odds(post, lr)
print(f"after_second_test_prob={odds_to_prob(post2):.6f}")

Running the script displays the exact numerical values for prior odds, likelihood ratio, posterior odds, and updated probabilities across both test stages.

Quantitative breakdown

Analyzing the calculations in the medical test scenario illustrates how odds update:

  1. Initial Odds Conversion: A prior probability of \(P = 0.01\) converts to prior odds \(O_{\text{prior}} = \frac{0.01}{1 - 0.01} = \frac{0.01}{0.99} \approx 0.010101\).
  2. Likelihood Ratio: With sensitivity \(\text{TPR} = 0.99\) and false positive rate \(\text{FPR} = 1 - 0.99 = 0.01\), the likelihood ratio is \(\text{LR} = \frac{0.99}{0.01} = 99.0\).
  3. First Posterior Update: Multiplying prior odds by the likelihood ratio gives posterior odds \(O_{\text{post1}} = 0.010101 \times 99.0 = 1.0\). Bounded back to probability space, \(P = \frac{1.0}{1.0 + 1.0} = 0.50\) (50%).
  4. Second Independent Update: Applying a second independent positive test with the same likelihood ratio multiplies the odds by 99.0 again: \(O_{\text{post2}} = 1.0 \times 99.0 = 99.0\). Converting back to probability yields \(P = \frac{99.0}{1.0 + 99.0} = 0.99\) (99%).

Pitfalls

  • Confusing Odds with Probability: Odds can exceed \(1.0\) (e.g., 3:1 odds corresponds to a probability of \(0.75\)). Passing raw odds into functions expecting probabilities produces invalid estimates.
  • Assuming Conditional Independence: Multiplying likelihood ratios for correlated tests overcounts evidence. If two diagnostic scans look for identical physical markers, a positive result on the second scan provides minimal new information.
  • Ignoring the Negative Likelihood Ratio: A negative test result does not mean probability drops to zero. A negative result updates odds using \(\text{LR}_- = \frac{1 - \text{Sensitivity}}{\text{Specificity}} = \frac{\text{FNR}}{\text{TNR}}\).

Key takeaways

  • Bayes in Odds Form: Posterior odds equal prior odds multiplied by the likelihood ratio (\(O_{\text{post}} = O_{\text{prior}} \times \text{LR}\)).
  • Likelihood Ratio Definition: \(\text{LR} = \frac{\text{Sensitivity}}{1 - \text{Specificity}}\). It measures diagnostic power independently of base rates.
  • Base-Rate Dominance: In rare-condition testing, low prior odds suppress posterior probability even when test accuracy is high.
  • Sequential Multiplicativity: Multiple conditionally independent evidence items multiply into prior odds sequentially.
