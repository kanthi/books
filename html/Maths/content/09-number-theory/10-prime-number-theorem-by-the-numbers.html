The Prime Number Theorem by the Numbers: pi(x), li(x) and Chebyshev’s psi

After reading this page, you will be able to implement an efficient NumPy sieve up to \(10^8\), evaluate the logarithmic integral \(\operatorname{li}(x)\) via Ramanujan’s series, measure the numerical error of prime counting approximations against theoretical bounds, and explain the equivalence of the Prime Number Theorem across \(\pi(x)\), \(\operatorname{li}(x)\), and Chebyshev’s \(\psi(x)\).

Thesis

The prime counting function \(\pi(x)\) counts the number of prime numbers less than or equal to \(x\). The Prime Number Theorem (PNT) describes the asymptotic distribution of primes, stating that as \(x \to \infty\),

\[ \pi(x) \sim \frac{x}{\ln x} \quad \text{or equivalently,} \quad \pi(x) \sim \operatorname{li}(x) \quad \text{or equivalently,} \quad \psi(x) \sim x. \]

All three statements say the same thing asymptotically, but they are very different in practice: \(\operatorname{li}(x)\) is far closer to \(\pi(x)\) than \(x/\ln x\). With a NumPy sieve we count primes up to \(10^8\) and compare all three. We look at how fast each converges, then at how the error \(\operatorname{li}(x) - \pi(x)\) relates to the Riemann hypothesis.

Mental model

To understand why different approximations to \(\pi(x)\) exist and how they relate to one another, consider the local density of prime numbers.

Function Definition / Expression Role / Meaning
\(\pi(x)\) \(\sum_{p \le x} 1\) Exact count of primes up to \(x\).
\(\frac{x}{\ln x}\) Naive asymptotic ratio The crude approximation; underestimates \(\pi(x)\) (by about 6% at \(10^8\)).
\(\operatorname{li}(x)\) \(\text{PV} \int_0^x \frac{dt}{\ln t}\) Integral of local density \(1 / \ln t\); accurate baseline approximation.
\(\psi(x)\) \(\sum_{p^k \le x} \ln p = \sum_{n \le x} \Lambda(n)\) Chebyshev’s function: primes and prime powers weighted by \(\ln p\); what analytic proofs work with.

The heuristic probability that a random integer near \(t\) is prime is approximately \(1 / \ln t\). Integrating this local density from 0 to \(x\) yields the logarithmic integral \(\operatorname{li}(x)\). The simpler expression \(x / \ln x\) corresponds to assuming a constant density of \(1 / \ln x\) across the entire range \([0, x]\). For \(2 \le t < x\) we have \(\ln t < \ln x\), so the true density \(1/\ln t\) is larger than \(1/\ln x\) over the range, and \(x/\ln x\) undercounts.

Chebyshev’s \(\psi(x)\) replaces the unit weight of each prime with \(\ln p\) and extends the sum to prime powers \(p^k\). These weights, von Mangoldt’s \(\Lambda(n)\), tie \(\psi\) directly to the logarithmic derivative of the Riemann zeta function \(\zeta(s)\) (see below).

Counting primes with a NumPy sieve

To get to \(10^8\) in reasonable time, the sieve never loops over individual numbers in Python. Each prime crosses off its multiples with one NumPy slice assignment.

The Sieve of Eratosthenes marks composite numbers by striding through a boolean array. Starting from a prime \(p\), multiples begin at \(p^2\) because smaller multiples \(k \cdot p\) (with \(k < p\)) have already been marked by smaller prime factors. By stepping with a stride of \(2p\), we skip even multiples, restricting updates entirely to odd indices.

At \(N = 10^8\), a boolean array of size \(10^8 + 1\) requires approximately 100 MB of RAM. Allocating a cumulative sum array of 64-bit integers would consume an additional 800 MB (8 bytes per integer). To preserve memory, we keep only the boolean sieve in memory and evaluate \(\pi(x)\) dynamically at specific checkpoint values of \(x\) using np.count_nonzero(is_prime[:x+1]). Extracting the prime indices into a dedicated 64-bit array yields 5,761,455 primes up to \(10^8\), using roughly 46 MB of memory.

Three approximations: \(x/\ln x\), \(\operatorname{li}(x)\), and local density

The principal value of the logarithmic integral is defined as:

\[ \operatorname{li}(x) = \lim_{\epsilon \to 0^+} \left( \int_0^{1-\epsilon} \frac{dt}{\ln t} + \int_{1+\epsilon}^x \frac{dt}{\ln t} \right). \]

For \(x \ge 2\) we compute it with Ramanujan’s series, which converges quickly. The loop in li stops once a term no longer changes the sum, well before its 200-term cap:

\[ \operatorname{li}(x) = \gamma + \ln(\ln x) + \sqrt{x} \sum_{n=1}^\infty \frac{(-1)^{n-1} (\ln x)^n}{n! \, 2^{n-1}} \sum_{k=0}^{\lfloor (n-1)/2 \rfloor} \frac{1}{2k+1}, \]

where \(\gamma \approx 0.5772156649\) is the Euler–Mascheroni constant.

The following Python script computes \(\pi(x)\), \(x/\ln x\), \(\operatorname{li}(x)\), Chebyshev’s \(\psi(x)\), and local mean prime gaps across powers of ten up to \(10^8\).

"""pnt.py: count primes with a sieve and compare pi(x) with x/ln x and li(x)."""
import math

import numpy as np

N = 10**8


def sieve(n):
    """Boolean array is_prime[0..n] (sieve of Eratosthenes, NumPy slicing)."""
    is_prime = np.ones(n + 1, dtype=bool)
    is_prime[:2] = False
    is_prime[4::2] = False
    for p in range(3, math.isqrt(n) + 1, 2):
        if is_prime[p]:
            is_prime[p * p :: 2 * p] = False
    return is_prime


def li(x):
    """Logarithmic integral li(x) = PV integral_0^x dt/ln t, via Ramanujan's
    rapidly converging series (fine for x >= 2 in double precision)."""
    L = math.log(x)
    total, term, inner, k = 0.0, 1.0, 0.0, 0
    for n in range(1, 200):
        term *= L / n                      # (ln x)^n / n!
        while k <= (n - 1) // 2:
            inner += 1.0 / (2 * k + 1)
            k += 1
        sign = -1.0 if (n - 1) % 2 else 1.0
        add = sign * term / 2 ** (n - 1) * inner
        total += add
        if abs(add) < 1e-17 * abs(total):
            break
    return 0.5772156649015329 + math.log(L) + math.sqrt(x) * total


is_prime = sieve(N)
primes = np.flatnonzero(is_prime)

print(f"{'x':>11} {'pi(x)':>10} {'x/ln x':>12} {'ratio':>7} {'li(x)':>12} {'li-pi':>7} {'sqrt(x)ln x':>12}")
for k in range(1, 9):
    x = 10**k
    pi = int(np.count_nonzero(is_prime[: x + 1]))
    a = x / math.log(x)
    l = li(x)
    print(f"{x:>11,} {pi:>10,} {a:>12,.0f} {pi / a:>7.4f} {l:>12,.0f} {l - pi:>7,.0f} {math.sqrt(x) * math.log(x):>12,.0f}")

# Chebyshev psi(x) = sum of ln p over prime powers p^k <= x; PNT <=> psi(x) ~ x.
print()
for k in (4, 6, 8):
    x = 10**k
    ps = primes[primes <= x]
    psi = 0.0
    for p in ps[ps <= math.isqrt(x)]:          # higher powers only for small p
        psi += math.log(p) * (int(math.log(x) / math.log(p)) - 1)
    psi += float(np.log(ps).sum())
    print(f"psi(10^{k}) / 10^{k} = {psi / x:.6f}")

# Average gap near x is about ln x.
for k in (4, 6, 8):
    x = 10**k
    window = primes[(primes > x - 100_000) & (primes <= x)] if x > 100_000 else primes[primes <= x]
    gaps = np.diff(window)
    print(f"mean prime gap below 10^{k} (last {len(window):,} primes): {gaps.mean():6.2f}   ln(10^{k}) = {math.log(x):6.2f}")

It was run with Python 3.13.5 and NumPy 2.5.4 and took about 3 seconds on the test machine. Most of that is the sieve.

The table and how to read it

Examining the output table yields key quantitative insights:

  1. Slow Convergence of \(\frac{\pi(x)}{x / \ln x}\): The ratio \(\pi(x) / (x / \ln x)\) starts at \(1.1605\) for \(x = 10^3\) and decreases slowly to \(1.0613\) at \(x = 10^8\). Asymptotic analysis shows that \(\frac{\pi(x)}{x / \ln x} \approx 1 + \frac{1}{\ln x}\), meaning the ratio approaches \(1\) very gradually.
  2. Precision of \(\operatorname{li}(x)\): At \(x = 10^8\), \(\pi(10^8) = 5,761,455\). The difference \(\operatorname{li}(10^8) - \pi(10^8) = 754\). The simple quotient is \(5,428,681\), which is \(332,774\) too low. So \(\operatorname{li}\) is about 440 times closer. The \(754\) agrees with published tables.
  3. \(\operatorname{li}(x) > \pi(x)\) on every row: \(\operatorname{li}\) overestimates, by an amount that grows but much more slowly than \(x\). Whether that lasts forever comes up below.

How good is \(\operatorname{li}(x)\)? Error bounds and the Riemann Hypothesis

The observed error \(\operatorname{li}(x) - \pi(x)\) is tiny next to \(\sqrt{x} \ln x\), the last column. At \(10^8\), the benchmark value \(\sqrt{x} \ln x \approx 184,207\), while the actual absolute error is only \(754\).

In 1901, Helge von Koch proved that the Riemann hypothesis (RH)—the assertion that all non-trivial zeros of the Riemann zeta function \(\zeta(s)\) lie on the critical line \(\operatorname{Re}(s) = 1/2\)—is logically equivalent to the error bound:

\[ |\pi(x) - \operatorname{li}(x)| = O(\sqrt{x} \ln x). \]

The table is consistent with RH, but it proves nothing. Any finite table is compatible with RH being false, and the big-\(O\) hides a constant. What is proved unconditionally is weaker; see the 1899 error term below.

Chebyshev’s \(\psi(x)\) and von Mangoldt weights

Chebyshev introduced two functions to simplify the analysis of prime distribution:

\[ \vartheta(x) = \sum_{p \le x} \ln p \quad \text{and} \quad \psi(x) = \sum_{p^k \le x} \ln p = \sum_{n \le x} \Lambda(n). \]

The von Mangoldt function \(\Lambda(n)\) equals \(\ln p\) if \(n = p^k\) is a prime power, and \(0\) otherwise.

In terms of complex analysis, \(\psi(x)\) is the most natural function to study because the logarithmic derivative of \(\zeta(s)\) yields the Dirichlet series generating function for \(\Lambda(n)\):

\[ -\frac{\zeta'(s)}{\zeta(s)} = \sum_{n=1}^\infty \frac{\Lambda(n)}{n^s} \quad (\operatorname{Re}(s) > 1). \]

Von Mangoldt’s explicit formula, derived from this with Perron’s formula, writes \(\psi(x)\) as a sum over the non-trivial zeros \(\rho\) of \(\zeta(s)\). It holds for \(x > 1\) not a prime power, with the zeros summed in pairs \(\rho, \bar\rho\) by increasing height:

\[ \psi(x) = x - \sum_{\rho} \frac{x^\rho}{\rho} - \ln(2\pi) - \frac{1}{2}\ln(1 - x^{-2}). \]

So the main term is exactly \(x\), and the zeros give the error. That is why \(\psi(x)/x\) is so close to 1 in our run: \(1.001340\) at \(10^4\), \(0.999587\) at \(10^6\) and \(0.999982\) at \(10^8\). The \(\ln p\) weights cancel the \(1/\ln t\) density, so there is no slowly shrinking \(1/\ln x\) term like the one in \(\pi(x)/(x/\ln x)\). In the code, each prime adds \(\ln p\) once. Then each prime \(p \le \sqrt{x}\) adds it \(\lfloor \log_p x \rfloor - 1\) more times, once for each higher power \(p^2, p^3, \dots \le x\). (The float log(x)/log(p) could misround at an exact power; it doesn’t at these \(x\), but an integer loop is safer.)

Prime gaps

Because \(\pi(x) \approx x / \ln x\), the global average gap between primes up to \(x\) is approximately \(\ln x\). Near \(x\), the average gap between consecutive primes is also about \(\ln x\), though individual gaps vary a lot.

Our numerical experiment measures the average gap between primes in a local window of the last 100,000 integers below \(x\): - Near \(x = 10^6\): Mean observed gap is \(13.84\), compared to \(\ln(10^6) \approx 13.82\). - Near \(x = 10^8\): Mean observed gap is \(18.34\), compared to \(\ln(10^8) \approx 18.42\).

For \(x = 10^4\), evaluating all primes below \(10^4\) yields a mean gap of \(8.12\), which is smaller than \(\ln(10^4) \approx 9.21\) because the window spans from \(2\) to \(10,000\), capturing the smaller gaps from lower ranges.

Historical proofs and analytical techniques

The journey to proving the Prime Number Theorem spans over a century of mathematical developments:

  1. Hadamard and de la Vallée Poussin (1896): Independently completed the first rigorous proofs of the PNT. Both proofs relied on demonstrating that the Riemann zeta function \(\zeta(s)\) has no zeros on the line \(\operatorname{Re}(s) = 1\).
  2. Zero-Free Regions and Error Terms (1899): De la Vallée Poussin established a zero-free region for \(\zeta(s)\) to the left of \(\operatorname{Re}(s) = 1\), yielding the explicit error bound: \[ \pi(x) = \operatorname{li}(x) + O\left(x \exp\left(-c \sqrt{\ln x}\right)\right). \]
  3. Elementary Proofs (1948–1949): Atle Selberg and Paul Erdős discovered elementary proofs of the PNT. These proofs avoided complex integration and properties of \(\zeta(s)\), and work with real-variable estimates, centred on Selberg’s symmetry formula for \(\Lambda(n)\).

Sign changes and Skewes’ number

On every row of our table \(\operatorname{li}(x) > \pi(x)\). The same holds as far as anyone has computed, past \(10^{19}\), and for a long time it was believed to hold always.

However, J. E. Littlewood proved in 1914 that the difference \(\operatorname{li}(x) - \pi(x)\) changes sign infinitely often.

Stanley Skewes (1933) produced the first explicit upper bound for the first crossing point (assuming the Riemann hypothesis), finding it to be below \(10^{10^{10^{34}}}\). Later unconditional work brought the bound down enormously. After Bays and Hudson (2000), with refinements by Saouter, Trudgian and others, the first sign change is known to occur somewhere below roughly \(1.4 \times 10^{316}\), near \(1.397 \times 10^{316}\). Nobody has found it, and it is far beyond anything a sieve can reach.

Formal mathematics and interactive theorem provers

The Prime Number Theorem has been machine-verified across several formal proof assistants:

  • Isabelle/HOL (2005): Avigad, Donnelly, Gray, and Raff formalized Selberg’s elementary proof of the PNT.
  • HOL Light (2009): John Harrison formalized the analytic proof of the PNT using complex analysis.
  • Lean 4 (PrimeNumberTheoremAnd, 2024): Launched in January 2024 by Terence Tao and Alex Kontorovich, this community project formalizes the PNT and related results, organised by a blueprint that maps out how the lemmas depend on each other.
  • Lean 4 (math-inc/strongpnt, 2025): In September 2025, Math, Inc. reported that its autoformalization system Gauss completed a Lean formalization of the strong Prime Number Theorem (including explicit error terms) in approximately three weeks. The resulting codebase spans roughly 25,000 lines of Lean, building upon components from PrimeNumberTheoremAnd.

Common mistakes

Mistake Cause Solution / Correct Understanding
Confusing \(\operatorname{li}(x)\) and \(\operatorname{Li}(x)\) \(\operatorname{li}(x) = \text{PV} \int_0^x \frac{dt}{\ln t}\), whereas \(\operatorname{Li}(x) = \int_2^x \frac{dt}{\ln t} = \operatorname{li}(x) - \operatorname{li}(2)\). Note the offset \(\operatorname{li}(2) \approx 1.04516\). Ensure consistent definitions when comparing error terms across literature.
Interpreting \(\frac{\pi(x)}{x/\ln x} \approx 1.06\) as failure Expecting rapid convergence to 1. The ratio behaves like \(1 + \frac{1}{\ln x} + \frac{2}{(\ln x)^2} + \cdots\). At \(10^8\) the first two terms give \(0.054 + 0.006 = 0.060\), close to the observed \(0.0613\). It is slow, and that is expected.
Precision breakdown in \(\operatorname{li}(x)\) series Evaluating \(\operatorname{li}\) near \(x = 1\), or for huge \(x\) in floats. \(\operatorname{li}(x) \to -\infty\) as \(x \to 1^+\): that is a real singularity, not a bug, and the code only claims accuracy for \(x \ge 2\). For very large \(x\) the alternating terms \((\ln x)^n/n!\) grow before they shrink and cancellation loses digits. Check against an arbitrary-precision library such as mpmath (not used here).
Memory overflow in large sieves Storing per-integer arrays such as a cumulative sum (800 MB at \(10^8\)). Maintain only the compact boolean sieve array (100 MB) and query slice sums via np.count_nonzero on demand.

Exercises

  1. Segmented Sieve up to \(10^9\): Modify pnt.py to process memory in 1 MB page segments, computing \(\pi(10^9)\) without keeping a \(10^9\)-element boolean array concurrently in memory.
  2. Riemann’s \(R(x)\) Function: Implement Riemann’s prime counting approximation \(R(x) = \sum_{n=1}^\infty \frac{\mu(n)}{n} \operatorname{li}(x^{1/n})\) using Möbius inversion, and compare its residual error \(R(10^8) - \pi(10^8)\) against \(\operatorname{li}(10^8) - \pi(10^8)\).
  3. Chebyshev’s Bias: Extend the prime filter to separate primes into residue classes \(p \equiv 1 \pmod 4\) and \(p \equiv 3 \pmod 4\). Check how often \(\pi(x; 4, 3) > \pi(x; 4, 1)\) for \(x \le 10^8\), and find the first \(x\) where it fails (it does).

Summary

The Prime Number Theorem establishes that primes become locally sparser at rate \(1/\ln x\). Integrating this density gives \(\operatorname{li}(x)\), which provides a far more accurate approximation to \(\pi(x)\) than \(x/\ln x\). Chebyshev’s \(\psi(x)\) translates the prime distribution into an equivalent form weighted by \(\ln p\), aligning prime counts with the zero distribution of the Riemann zeta function \(\zeta(s)\). While \(\operatorname{li}(x) > \pi(x)\) for all accessible computation up to \(10^8\), Littlewood showed the error changes sign infinitely often, with the first crossing proven to occur below \(1.4 \times 10^{316}\). The PNT itself has been machine-checked in Isabelle, HOL Light and Lean, and a strong form with an explicit error term has been checked in Lean.
