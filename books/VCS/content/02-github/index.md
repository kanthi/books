# GitHub

Git is the version-control tool. **GitHub** is a product on top of Git: hosting, pull requests, Actions, security, orgs, and the API. This part assumes remotes, branches, and commits from the Git part.

These chapters are **seeds** moved out of Git. The expansion syllabus (identity, rulesets, merge queue, OIDC, `gh`/API, Enterprise Cloud vs Server) lives in `content/_planning/SYLLABUS.md` and will be filled in a later pass.

| Section | Seed |
|---------|------|
| **Introduction** | Accounts, repos, Git vs GitHub |
| **Collaboration** | Forks, pull requests, issues, boards |
| **Actions** | Map → triggers → jobs → secrets → matrix → cache → CI → reuse → custom actions → security/OIDC → operate |
| **Platform** | Pages, Packages, API, `gh` |
| **Open source** | Contributing and maintaining |
| **Orgs and teams** | Branch protection, reviews, team process |
