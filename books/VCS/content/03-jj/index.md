# Jujutsu

**Jujutsu (`jj`)** is its own version-control system. It can sit on a Git repo (colocated), but the model is not Git: change IDs, no index, working-copy commit `@`, revsets.

This part is a **seed**. The current overview chapter is the old Misc page. A full JJ curriculum (current `jj`, colocated workflows, undo, bookmarks, `jj git push`) comes in a later pass. Do not treat this seed as complete.
