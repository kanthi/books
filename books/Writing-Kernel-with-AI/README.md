# Writing Kernel with AI

A comprehensive, production-grade guide to accelerated computing and GPU kernel engineering: CPU to AI-written kernels.

- **Baseline:** CUDA, Triton, CUTLASS / CuTe-DSL, Hopper / Blackwell
- **Curriculum:** 6 Parts, 20 Chapters, and Industry Capstones (with Crusoe)

## Preview

From the monorepo `books/` directory:

```bash
cd books
./indipub.sh Writing-Kernel-with-AI --html
./indiprev.sh Writing-Kernel-with-AI
```

Regenerate the sidebar after adding or renaming chapters:

```bash
cd Writing-Kernel-with-AI
bash scripts/update-index.sh
```

Do not hand-edit `_quarto.yml`.
