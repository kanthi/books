# Boring Rust

A Complete Guide to Safe, Concurrent, High-Performance Programming.

- **Baseline:** Rust 2024 Edition (Stable toolchain)
- **Toolchain:** `rustup`, `cargo`, `rustc`
- **Examples:** Complete runnable listings inline in each chapter

## Preview

From the monorepo `books/` directory:

```bash
cd books
./indipub.sh Boring-Rust --html
./indiprev.sh Boring-Rust
```

Regenerate the sidebar after adding or renaming chapters:

```bash
cd Boring-Rust
bash scripts/update-index.sh
```

Do not hand-edit `_quarto.yml`.
