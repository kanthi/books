# Capstone Wrap-Up and Career Roadmap

## Final Integration Checklist

- architecture documented clearly
- test strategy includes failure paths
- observability and runbook complete
- performance and security baselines recorded
- CI gates enforce quality standards

## Portfolio Packaging

For each project include:

- problem statement
- architecture decisions and tradeoffs
- key code excerpts
- measured outcomes (latency, error rate, reliability)
- lessons learned and next iteration plan

## Specialization Tracks

1. Backend/API Engineering
- async services, data modeling, protocol design

2. Platform/Infrastructure Engineering
- service reliability, deployment automation, observability

3. Embedded/Edge Engineering
- `no_std`, hardware interfaces, real-time behavior

4. Security Engineering
- threat modeling, hardening, dependency governance

## 90-Day Growth Plan Template

- Weeks 1-4: deepen one specialization with mini-projects.
- Weeks 5-8: contribute to open-source Rust codebase.
- Weeks 9-12: publish technical writeup and refined capstone.

## Final Advice

Keep building in public. Consistent, measurable engineering work is the strongest signal of Rust expertise.

## Interview Prep from Your Projects

Prepare concise narratives for:

- hardest bug and resolution strategy
- largest performance gain and measurement method
- security design decisions and tradeoffs
- incident handling and reliability improvements

## Open Source Contribution Strategy

1. pick one active Rust crate in your target domain
2. submit docs/test improvements first
3. move to focused bug fixes
4. publish short technical writeups after each merged PR
