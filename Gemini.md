# Gemini Repository Memory & Instructions

This repository contains a collection of technical books managed with Quarto.

## 🛠️ Repository Structure
- **/books**: Main directory containing all book projects (e.g., `Go`, `Linux-Commands`).
- **/books/[BookName]/content**: Source files (`.qmd`) for book chapters.
- **/books/[BookName]/scripts**: Automation scripts for the specific book.
- **/published_books**: Local output directory for rendered books (ignored by git).

## ⚡ Automation & Autogeneration
- **CRITICAL**: Do NOT manually edit `_quarto.yml` inside book directories.
- **Autogeneration**: `_quarto.yml` is automatically generated by the script `scripts/update-index.sh` located in each book's directory.
- **Trigger**: The root script `renderpub.sh` orchestrates the rendering of all books and calls the individual `update-index.sh` scripts.

## 📝 Adding New Content
1. **Create File**: Add your `.qmd` or `.md` file in the relevant `content/` subdirectory.
2. **Ordering**: Use numeric prefixes (e.g., `01-`, `01a-`, `02-`) to control the appearance order in the sidebar.
3. **Update Index**: Run `bash scripts/update-index.sh` from the book's root directory to update its `_quarto.yml`.
4. **Cross-links**: Manually update "Related Topics" or cross-chapter links in the `.qmd` files as needed.

## 🚀 Deployment (CI/CD)
- The repository is hosted on GitHub.
- **GitHub Actions**: Automated workflows handle the generation and publishing of books upon commits.

## 🧠 Memory for Gemini
- Always check for the existence of `scripts/update-index.sh` before modifying any book structure.
- Respect the naming convention for chapter files to ensure correct sorting.
- Any change to the book structure (adding/removing files) requires a run of the update script to synchronize the configuration.
